# Literature Review

## 流程

1. **明确问题**：研究问题 + 纳入/排除标准（时间范围、语种、文献类型）。
2. **多源检索**：优先 `mcp__papers__*`（arXiv/Semantic Scholar/Crossref）；无数据源时用 `web_search` + 出版社/会议官方页面。
3. **去重与筛选**：按标题/摘要初筛，记录每步数量。
4. **归纳**：按主题/方法/结论聚类，标注代表性工作与分歧。
5. **综述输出**：结构化综述（背景 → 主要方向 → 代表工作表 → 争议 → 研究缺口），每条引用带来源。

## 硬性规则

- **绝不虚构引用**：每条文献必须真实可查，给出 DOI/arXiv id/URL 至少其一；无法核实的引用直接删掉或标注"未核实"。
- 引用格式统一（如 [作者, 年份, 标题, 出处]）。
- 综述中区分"作者观点"与"你的归纳"。
