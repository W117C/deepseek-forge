# Paper Analysis

## 报告框架

1. **元信息**：标题、作者、机构、年份、出处（会议/期刊/arXiv）、DOI/链接。
2. **问题**：论文要解决什么问题？为什么重要？
3. **方法**：核心思路、模型/算法、与既有工作的关键差异。
4. **实验**：数据集、基线、指标、主要结果（表格化）。
5. **可信度评估**：实验是否支撑结论？有哪些未控制变量/潜在偏差？
6. **局限与后续**：作者承认的局限 + 你的批判 + 可延伸方向。

## 硬性规则

- 若拿不到原文：明确说明只有摘要/二手信息，并标注信息来源。
- 引用原文关键句时给出章节/页码（或段落位置）。
- 结论区分"论文声称"与"证据强度"。
