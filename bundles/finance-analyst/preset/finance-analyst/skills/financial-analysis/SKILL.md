# Financial Analysis

结构化金融分析流程。每一步都要标注数据来源（URL 或数据工具名）与时间点。

## 工作流程

1. **明确对象与口径**：标的（代码/公司）、时间区间、币种、市场。
2. **取数**：优先用可用数据工具（`mcp__marketdata__*`、`web_search`、`web_fetch`）；无 token 时用 `web_search`/官方财报页面。
3. **核对**：同一指标至少两个来源交叉验证；数据缺口显式说明。
4. **分析**：基本面（营收/利润/现金流/负债）、估值（PE/PB/EV/EBITDA 与同行对比）、技术面（趋势/支撑/量能，注明仅为统计描述）、风险（集中度/汇率/政策/流动性）。
5. **结论**：结论要可证伪——每条判断附证据；给出"还需要什么数据才能更确定"。

## 硬性规则

- **不构成投资建议**：输出是研究与决策支持，不是买卖指令。
- **不执行交易**：不调用任何下单/转账能力。
- 引用数据必须带来源与日期；不确定的数值写明"估算/未核实"。
- 用户要"预测股价"时：改为给出情景分析（乐观/基准/悲观 + 概率 + 触发条件）。
