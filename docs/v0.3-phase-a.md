# v0.3 Phase A 实施记录：SQLite 数据层

> 状态：✅ 完成（15 套 e2e 219/219 全绿，其中新增 e2e-sqlite 16/16）。

## 变更内容（增量，无重写）

- **新增 `lib/db/sqlite.mjs`**：node:sqlite（Node 22 内置，零依赖，Experimental 警告已知）存储层。
  - schema_version 表 + 迁移框架（MIGRATIONS 数组按序应用，事务包裹，失败回滚）；当前 SCHEMA_VERSION = 1。
  - v0.3 规范十表：publishers / packages / package_versions / artifacts / dependencies / security_scans / ratings / installations / audit_logs / api_tokens（外键 + ON DELETE CASCADE + 唯一约束 + WAL + busy_timeout）。
  - 内存工作形态保持旧 db 对象（agents/publishers/pending/catalog/publisherTokens）——服务端业务逻辑零改动；persist() = 单事务全量重写（当前规模合理，原子性优于旧 JSON 全量写）。
  - **旧 registry.json 一次性迁移**：首次打开时读入并写 SQLite，原文件改名 registry.json.migrated（可回滚保留）。
  - **令牌哈希落库**：api_tokens 存 sha256(token)；注册端点返回明文一次，重复注册返回 token:null（CLI 保留既有令牌）；鉴权改为哈希比较——修复了旧实现"令牌明文落盘"的问题。
- **registry-server.mjs**：仅替换 load/persist 为 openStore；发布/审核/注册三处增加 audit_logs 埋点；register 幂等语义保持（公钥一致即成功）。
- **备份脚本**：scripts/backup.sh 在 tar 前调用 `node lib/db/checkpoint.mjs`（WAL TRUNCATE），保证备份自洽。
- **e2e-sqlite.mjs（新增 16 项）**：forge.db 生成、schema_version=1、十表齐备、packages/versions/artifacts/scans 行内容、令牌哈希、审计日志、**重启持久化**（关→开→数据/签名/制品完整）、**旧 JSON 迁移**（.migrated 改名 + 旧 Agent 可用 + 旧明文令牌自动哈希）。

## 兼容性保证

- 全部旧 14 套 e2e（203 项）在 SQLite 底层上**逐项通过**——对外 API 行为不变。
- CI 的 `for t in test/e2e*.mjs` 自动纳入 e2e-sqlite。

## 已知边界（Phase B/C 处理）
