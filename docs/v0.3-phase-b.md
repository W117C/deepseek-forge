# v0.3 Phase B 实施记录：Package/Version/Artifact 模型层

> 状态：✅ 完成（16 套 e2e 230/230 全绿，其中新增 e2e-phase-b 11/11）。

## 变更内容（增量，旧端点全保留）

- **SemVer（lib/semver.mjs，零依赖）**：parse/校验/比较/排序（MAJOR.MINOR.PATCH[-pre][+build]，正式版 > 预发布；单测覆盖 rc/非法/排序/latest）。发布时校验 version 必须合法 SemVer（非法 → 400）。
- **统一包状态机**：status ∈ draft/submitted/scanning/review/published/deprecated/yanked/blocked（当前实流使用：pending → 'submitted'（待审）→ 审批通过 → 'published' 或（扫描 verdict=block 时）'blocked'）。状态落在 packages/package_versions 两表；detail 与 /v1/packages 视图返回 status。客户端安装门禁升级为 trust==='blocked' **或** status==='blocked' 双检查。
- **/v1/packages 泛化端点（规范模型视图，旧 /v1/agents 并存兼容）**：
  - GET /v1/packages：全部包（id/slug/name/type/description/publisher/publisherProfile/category/tags/status/trust/score/installs/ratings{avg,count}/latest/versions/createdAt/updatedAt）
  - GET /v1/packages/:slug：包详情（同上）
  - GET /v1/packages/:slug/versions：SemVer 降序版本列表（每版本 manifest/sha256/signature/scan/签名 artifactUrl）
  - GET /v1/packages/:slug/:version/artifact：制品（与 /v1/agents 制品同一条处理链，签名 URL + 限速）
- **Publisher 模型**：register 端点接受可选 profile（name/slug/website/github/avatar/description）→ publishers 表各列 + 内存 db.publisherProfiles；新增 GET /v1/publishers/:id（publicKey + profile + 名下包列表）；detail 与 packages 视图携带 publisherProfile。私钥依旧永不上传（只存公钥）。
- **dependencies 表实际写入**：persist 时从最新版本 manifest.components.bundles 写入（dep_name + dep_constraint），e2e 断言 finance-analyst → @agenthub/finance-core。
- **SQLite 同步**：publishers 11 列 profile、packages/versions 的 status、dependencies 行、publisherProfiles 读回。
