# v0.3 Phase C 实施记录：Marketplace 前端接通真实 API（消除 mock 依赖）

> 状态：✅ 完成（服务端 16 套 e2e 230/230 保持全绿；forge typecheck + 生产构建通过；landing 构建通过；新增 e2e-forge-api 10/10）。

## 变更内容（增量，UI 组件与样式零改动）

- **CORS**：registry-server 支持 corsOrigins（null=公共只读放行 / 数组=白名单）；GET/POST/OPTIONS + authorization 头；OPTIONS 预检 204（e2e 契约实测）。
- **forge/src/api/（13 模块，规范落实）**：client（registryBase：VITE_REGISTRY_URL / ?registry= 查询参数 / 同源回退 + ApiError）/ packages / agents / bundles / plugins / skills / search / versions / security / publish（注册发布者 + CLI 命令生成）/ ratings / install（幂等上报）+ index。页面不再直拼 fetch。
- **lib/registry.ts 重写**：删除 mock 导入；新增 mapApiPackage（ApiPackage → 展示模型：install/rating/security/versions/publisherProfile 全部来自真实数据）；authorOf 改读 publisherProfile；makeVersions 改为真实版本列表（无数据时退回单版本）；relatedPackages 保留（pool 显式传入）。
- **context/app.tsx**：allPackages 由 listPackages() 加载（loading/error/refresh 状态）；install(id, version) 触发匿名安装上报（eventId 幂等）+ 本地已装标记；移除 localStorage 假发布（published/publishPackage 删除）。
- **页面与组件**：Home（真实数据 + loading/错误态 + 真实安装数排行）；Publish 重写为真实发布向导（CLI keygen → 浏览器只传公钥注册 → 令牌一次性展示 → 复制发布命令；私钥永不上浏览器）；SearchBar/CommandPalette/filters 静态常量迁移到 lib/site.ts。
- **mock.ts 已删除**：全仓无任何 `data/mock` 引用（构建门槛兜底）。

## 安全语义（保持并强化）

- 浏览器端永不接触发布者私钥：发布签名只在用户本机 CLI 完成；Web 发布向导只做公钥注册与命令引导。
- 前端只读数据 + 匿名安装上报 + 评分（限流）；写端点鉴权（Bearer/operatorToken）不受 CORS 放行影响——CORS 只控制浏览器可访问性，鉴权仍在服务端校验。
